# Клуб Семейного Отдыха — контент для @klub.semeinogo.otdyha

- `queue.json` — очередь публикаций (status: ready → published). Рилсы (video_url) и карусели (slides), ссылки raw.githubusercontent.
- `src/photos`, `src/clips` — исходники дома. `src/clips/cinema.mp4` уже с замазанным названием фильма; `cinema_orig.mp4` в рилсы не ставить.
- `tools/carousel.py specs/<id>.json` — собирает карусель в `carousels/<id>/`.
- `tools/reel.py specs/<id>.json` — собирает рилс (1080x1920) из клипов с субтитрами.
- Публикация: Instagram через Composio, аккаунт `klub.semeinogo.otdyha` (ig_user_id 39807824388832187).
- Правила контента: без цен; только факты, которые есть в старых подписях (бассейн под куполом, баня на дровах, чан, кино у костра, до 6 гостей в цене / до 8, дети до 3 лет бесплатно, игровая и манеж, летом аквапарк, контактный зоопарк рядом); бронь — группа в MAX.
